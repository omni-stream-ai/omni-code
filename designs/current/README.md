# 当前应用界面基准

此目录直接使用当前 Flutter 页面生成预览，替代此前改版提案作为现状参考。没有修改应用视觉或布局。

## 覆盖范围

工作台、会话、项目详情、设置；移动尺寸 390 × 844、桌面尺寸 1440 × 900；每页提供深浅主题，核心页面共 16 张，另有会话渲染与状态 32 张，另有命令与输入辅助 20 张，共 68 张。全部截图见上方分组；也可使用 [HTML 浏览器](../index.html)。

预览使用当前页面、AppTheme 和响应式布局，数据来自测试夹具，并非真实用户数据。语言为英语；测试环境显式加载 Roboto 和 MaterialIcons，等宽字体不可用时及按钮空字体使用 Roboto 替代测试框架默认方块字体。截图生成时启用真实阴影模糊，避免测试默认设置把阴影绘制成实心色块。系统字体、平台能力、窗口装饰及真机渲染可能有差异。设置页的模型加载提示来自未接入真实服务的测试环境。

会话补充场景：Markdown 标题、加粗、行内代码、列表、代码块、表格、引用和链接；工具摘要、调用历史与输出详情；文件变更摘要与 diff 详情；执行中、执行失败。各场景提供移动端、桌面端及深浅主题，详情弹窗通过实际点击打开。图片消息沿用核心会话页。

命令与输入辅助：`/` 斜杠命令列表、`/rev` 筛选、点击 `/review` 填入输入框、`$skill` 技能建议、`@lib/` 文件引用建议。使用示例接口返回的命令与文件，展示当前补全组件，不代表所有提供方均支持这些命令；截图不包含系统软键盘。

当前范围尚未覆盖全部路由、弹层和业务状态，例如审批、排队、断线重连、流式增量与媒体加载失败等，不能视为全状态覆盖。历史 main.op、tokens.json、coverage 和 states 的画稿均不能作为现状视觉证据。本次未制作新的可编辑矢量稿，也未声称全量现状还原已经完成。

## 重新生成

在项目根目录、可用的 Flutter 开发环境中运行：

```sh
flutter test --no-pub --update-goldens --dart-define=UPDATE_CURRENT_APP_PREVIEWS=true test/generate_readme_previews_test.dart
```

生成器复用应用页面与示例接口，需随当前接口同步维护。预览色值摘录见 source-colors.json；派生颜色、别名及页面覆盖仍以源码为准。source-manifest.json 记录本轮截图对应的关键源码哈希，源码变化后应重新导出。
