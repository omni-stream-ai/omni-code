# 桌面端快捷键

Windows、Linux 和 macOS 支持应用内快捷键。在输入框中也可使用；编辑快捷键时会暂停触发应用操作。

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 搜索项目和会话 | Ctrl+P | Cmd+P |
| 新建独立窗口 | Ctrl+N | Cmd+N |
| 新建会话 | Ctrl+Shift+N | Cmd+Shift+N |
| 上一个最近会话 | Ctrl+Alt+↑ | Cmd+Alt+↑ |
| 下一个最近会话 | Ctrl+Alt+↓ | Cmd+Alt+↓ |
| 打开设置 | Ctrl+, | Cmd+, |
| 返回首页 | Ctrl+Shift+H | Cmd+Shift+H |
| 打开项目列表 | Ctrl+Shift+P | Cmd+Shift+P |
| 展开或收起导航栏 | Ctrl+B | Cmd+B |
| 返回上一页 | Alt+← | Cmd+← |

搜索弹窗支持按项目名称、路径、会话标题和所属项目筛选，使用 ↑ / ↓ 选择，Enter 打开，Esc 关闭。

进入项目的会话列表后，默认聚焦第一个会话，按 Enter 打开。使用 ↑ / ↓ 在列表中切换焦点，Tab / Shift+Tab 按页面顺序切换焦点。Ctrl+Shift+N（macOS 为 Cmd+Shift+N）直接在当前项目中新建会话，也支持在设置中自定义。

在会话详情页（包括输入框获得焦点时），可按上述快捷键在侧栏显示的最近五个会话中上下切换，顺序和「当前项目／全部项目」筛选与侧栏一致。到达首尾后停止；如果当前会话不在列表中，↓ 打开第一项，↑ 打开最后一项。切换不会累积会话页面，打开弹窗时暂停切换。侧栏「最近会话」标题下显示当前组合键，也可点击提示切换。

桌面侧栏的搜索、新窗口和新会话入口会显示当前按键组合，首页搜索框也可点击按键提示打开搜索。鼠标悬停在导航操作上可查看快捷键。侧栏常驻「快捷键指南」，搜索弹窗底部也提供操作说明和指南入口。自定义或禁用快捷键后，这些提示会同步更新。

在「设置 → 键盘快捷键」中点击编辑按钮，然后按下新的组合键并保存。可使用 Ctrl、Alt、Cmd/Meta 加其他按键，或 F1–F24 功能键。重复绑定会显示冲突提示。还可以禁用单项、恢复单项默认值或恢复全部默认值。

修改后立即生效，并通过与语言、主题等设置相同的设置存储自动保存，重启应用后仍保留。已有设置无需迁移；未自定义的项目使用所在平台的默认快捷键。
