# Omni Code 产品需求文档

Omni Code 让用户通过手机或桌面客户端，连接自己的开发环境，用自然语言驱动 Agent 完成开发任务。Codex、Pi 为主要接入，其他 Agent 通过 ACP 扩展；安装、启动和配置尽量自动完成。

## 编写与交付约定

需求正文描述产品应提供的体验，不因尚未实现而削弱要求。每个需求有唯一编号和验收条件；实现状态集中维护在 07，便于按目标评审、按状态交付。

- **待完善**：已有相关能力，尚未满足本版完整需求。
- **未实现**：目标体验尚未形成可交付闭环。
- **待验收**：完整实现已提交，等待发布验收。
- **已验收**：在明确版本、平台与环境通过验收，有验收记录。

本版不将任何需求标为已验收。“待完善”也不代表生产验证通过。分期是建议顺序；正式发布日期、首发平台和外部工具支持清单另行确定。
