# 04 语音与应用设置

## 1. 执行摘要

语音和通知让用户离开电脑后仍能推进任务；设置应减少重复填写，并使授权、服务选择和故障处理可理解。语音可以关闭，不影响文字主流程。

成功标准：取消录音不提交，识别失败不发送空需求，停止通话不继续监听，通知不重复触发操作，更新失败可继续使用旧版。

## 2. 用户体验与功能

### SP-01 语音输入

**故事**：作为用户，我希望把讲话转为可编辑或直接发送的需求。

**验收条件**：

- 首次使用按需请求麦克风权限；拒绝后提供系统设置引导，文字输入继续可用。
- 支持按住说话、取消、插入草稿；直接发送须由用户明确选择，默认允许先编辑识别结果。
- 录音中、识别中、失败和完成分别展示；取消不发送，空结果不提交。
- 插入保留原草稿及光标位置；退出页面和取消后释放录音资源。
- 录音失败或服务不可用时可重试，提示是否需要重新录音；临时音频按数据策略清理。

### SP-02 连续通话

**故事**：作为用户，我希望持续说话并收听回复，随时结束或打断。

**验收条件**：

- 通话有明确的监听、识别、等待 Agent、播报、暂停与错误状态。
- 显示字幕，自动提交前支持可配置的确认策略；对可能产生重大影响的执行仍遵守审批。
- 可调停顿分句；打断仅在服务支持时开放，不支持时说明并提供停止播放按钮。
- 避免将自身播报循环识别为新需求；检测不确定时暂停提交并提示。
- 退出通话立即停止监听与播报，不提交迟到识别结果；应用后台行为遵守平台权限并向用户说明。
- 识别或播放失败可降级为文字交互，不造成重复任务。

### SP-03 语音服务与扩展

**故事**：作为用户，我希望系统推荐可用语音方案，必要时由 Agent 帮我配置。

**验收条件**：

- 区分批量识别、实时识别和语音合成，默认推荐经过验证且适配当前平台的方案。
- 优先复用系统能力和已有凭据，只询问无法获取的信息；手动端点和模型作为高级选项。
- 保存后执行对应能力测试，分别展示识别文字、实时事件或可播放音频。
- 切换或移除服务前提示对当前通话的影响，失败保留最后可用配置。
- 安装服务时显示执行发生在客户端还是开发机；不因点击测试而暗中运行安装命令。
- 云端处理前说明音频和文本去向；可选择仅本地方案，但仅在当前平台具备能力时展示。

### SP-04 本地语音与模型管理

**故事**：作为用户，我希望下载本地模型后使用语音，了解存储和运行条件。

**验收条件**：

- 仅展示受支持平台及满足条件的本地能力，明确所需空间与资源。
- 模型下载支持进度、取消、失败重试、校验和删除；退出页面后可再次查看真实进度。
- 下载完成且校验通过后才允许启用；模型损坏可修复，不误显示可用。
- 唤醒词默认关闭，启用前说明监听范围和功耗；不支持后台唤醒时明确提示。
- 服务端语音管理、音色与说话人能力只有验证可用后才开放入口，不保留看似可用的死入口。
- 删除正在使用的模型先处理引用，避免留下无效默认配置。

### SP-05 回复播报

**故事**：作为用户，我希望按需朗读回复，或选择自动播报。

**验收条件**：

- 自动播报默认关闭；可随时停止，切换会话不继续播报无关回复。
- 同一回复不因重连重复自动播报；跳过不适合朗读的工具负载和秘密。
- 音频为空或播放失败有反馈，可使用文字；支持的系统/云端方案分别验证。
- 语速、音色等仅展示当前方案支持项；长回复可分段但不漏掉关键错误。

### ST-01 设置与偏好

**故事**：作为用户，我希望设置能保存和同步，修改失败时知道哪些生效。

**验收条件**：

- 语言、主题、通知、语音、连接、默认 Agent/模型有合理默认值，重启后保留。
- 区分设备偏好、宿主机设置、项目设置与本轮覆盖，展示生效范围。
- 可用自然语言请求配置，修改执行前显示必要摘要；保留手动编辑入口。
- 本地保存与远端保存分别反馈，部分失败不能显示全部成功。
- 配置损坏有恢复默认、保留备份和重新连接路径，不清空所有设置后静默启动。

### ST-02 通知与任务提醒

**故事**：作为用户，我希望收到需要处理或已完成的任务提醒，并直接进入对应位置。

**验收条件**：

- 审批、等待输入、任务完成、失败分别设置，支持静音和预览隐私选项。
- 当前会话已可见的更新不反复通知；跨通道重复事件去重。
- 点击通知进入正确宿主机与会话；未连接先恢复连接，无权限时说明原因。
- 不同推送通道单独验证送达与点击，不把后台限制宣传成永久在线。
- 系统通知被禁用或推送不可用时有状态提示，不阻断前台主流程。

### ST-03 更新与版本兼容

**故事**：作为用户，我希望安全更新客户端和服务，失败后还能继续工作。

**验收条件**：

- 展示当前版本、新版本、变更摘要、兼容性和是否影响任务。
- 下载可取消和重试，安装前校验来源与完整性；校验失败不执行安装。
- 客户端与 Bridge 不兼容时给出升级顺序和兼容模式，禁止不兼容写操作。
- 更新不静默中断运行任务；数据迁移失败可恢复，旧版可运行范围明确。
- 不支持应用内更新的平台提供准确的安装渠道，不展示无效按钮。

### ST-04 诊断与隐私

**故事**：作为用户，我希望快速定位故障，并控制诊断数据的分享。

**验收条件**：

- 诊断区显示连接、工具、模型、语音和验收环境状态，提供针对性修复动作。
- 可复制脱敏摘要或导出诊断包；导出前可预览，不包含密钥、令牌与完整私有文件。
- 可选遥测首次说明用途与范围，默认关闭；本地运行所需日志与上传遥测分别管理。
- 关闭遥测后停止后续上传；不影响本地故障排查和核心任务。

## 3. AI 系统要求

语音评估覆盖安静/噪声、中英文、长停顿、空录音、回声、重复事件和中途断网。自动配置语音服务遵循 TG 的验证与恢复约束；不以模型推荐代替服务能力检测。

## 4. 技术规格

语音能力、执行位置和数据去向分别标识；敏感配置独立保存。通知携带可校验的对象引用，不携带可复用长期令牌。更新有完整性校验、兼容策略和恢复记录。

## 5. 风险与路线图

优先文字流程、基础语音输入、通知和设置可靠性；连续通话、唤醒词、本地模型管理随后按平台开放。每种语音方案单独验收，未通过的平台隐藏相关入口。状态见 07。
