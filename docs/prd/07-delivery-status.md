# 07 交付与实现状态

## 1. 执行摘要

先按完整体验定义需求，再按实现状态和验收结果交付。状态以本版完整需求为单位：有部分基础能力仍标记待完善，尚无闭环标记未实现；完成开发后再进入待验收，验收通过后记录版本与平台。

本表是交付规划，未包含上线承诺。所有模块必须通过 06 中与其相关的生产门槛才能发布。

## 3. AI 验收要求

每个涉及 Agent 的工作包同时交付：正常环境用例、故障环境用例、权限与注入样本、真实工具结果以及人工核对结论。配置成功不只检查文本，审批成功不只检查模型输出，验收成功不只检查最终总结。

关键用例包括：没有任何可用 Agent、Codex 未登录、Pi 无模型、多版本冲突、ACP 协议不兼容、安装成功但不可执行、错误凭据、网络中断、写入失败、无证据验收、越权命令和重复请求。

## 4. 交付规格与验收记录

每个交付项记录需求 ID、目标平台、工具版本、测试环境、正常/异常用例结果、已知限制、恢复方法和负责人。状态流转：待完善/未实现 → 待验收 → 已验收；需求有实质变更或回归失败时退回待完善。

已验收记录必须带应用版本与日期。开发自测不替代发布验收；试用范围也必须明确支持清单和关闭的能力。
